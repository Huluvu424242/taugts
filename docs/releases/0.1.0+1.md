# Taugt’s? 0.1.0+1

Dies ist die erste Android-Veröffentlichung von **Taugt’s?**, einer
Offline-first-App zum lokalen Erfassen und Bewerten von Produkten, Orten und
Erlebnissen.

## Enthalten

- lokale Produktverwaltung für Bier und andere Produkte
- lokale Ortsverwaltung mit Ortstyp und optionalen Detailangaben
- Erlebnisentwürfe mit Zeitpunkt, Produkt, Ort, Preis, Menge, Gebinde und Notiz
- Getränkebewertungen mit geordneten, optionalen Qualitäts- und
  Intensitätskriterien
- unabhängiges Gesamturteil ohne automatische Verrechnung der Einzelwerte
- historische Bewertungen: Ein neues Erlebnis erzeugt einen neuen
  Bewertungsstand; eine Korrektur ändert nur die ausgewählte Erlebnisbewertung
- lokales Profil als Herkunftskennung
- App-Logo und Android-Launcher-Icons
- offline verfügbare Barrierefreiheitserklärung
- kontextbezogene Vorbereitung von Bugreports zur Prüfung auf GitHub

## Datenschutz und Datenhaltung

Alle fachlichen Daten werden ausschließlich lokal auf dem Gerät gespeichert.
Diese Version besitzt keine Telemetrie, keine versteckte Synchronisation und
benötigt für ihre Kernfunktionen keinen Server. Nur wenn ein Bugreport bewusst
vorbereitet wird, öffnet die App die entsprechende GitHub-Seite im Browser; der
Bericht wird dort erst nach Prüfung durch den Nutzer abgesendet.

## Bekannte Einschränkungen

- Import und Export sind noch nicht enthalten.
- Restaurantbesuche und Einkäufe stehen noch nicht als vollständige
  Ereignisabläufe zur Verfügung.
- Windows und Linux sind vorbereitet, werden mit dieser Version aber nicht
  veröffentlicht.
- Die systematische manuelle Barrierefreiheitsprüfung mit TalkBack, großer
  Systemschrift, Gestennavigation und einem kleinen Android-Gerät ist vor einer
  öffentlichen Freigabe noch abzuschließen; siehe Story #30.
- Die Anwendung befindet sich in einem frühen Entwicklungsstand. Vor einer
  Neuinstallation oder einem Wechsel des Signierschlüssels gibt es noch keinen
  Exportweg für lokal gespeicherte Daten.

## Installation

1. Die Datei `taugts-0.1.0+1.apk` und
   `taugts-0.1.0+1.apk.sha256` aus diesem GitHub Release herunterladen.
2. Die SHA-256-Prüfsumme prüfen.
3. Unter Android gegebenenfalls die Installation aus der verwendeten
   Download-App beziehungsweise dem Browser erlauben.
4. Die APK öffnen und die Installation bestätigen.

Spätere APK-Updates funktionieren nur, wenn sie mit demselben
Release-Keystore signiert wurden.

## Prüfsumme unter Windows kontrollieren

```powershell
Get-FileHash .\taugts-0.1.0+1.apk -Algorithm SHA256
```

Der ausgegebene Hash muss mit dem Inhalt der Datei
`taugts-0.1.0+1.apk.sha256` übereinstimmen.
