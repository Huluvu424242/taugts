# Taugt’s? 0.1.0+3

Diese Android-Version von **Taugt’s?** erweitert die vollständig lokale
Bewertung von Produkten, Orten und Erlebnissen um konfigurierbare Kriterien,
historische Verläufe sowie bewusst gestartete Barcode-, Standort- und
Kartenfunktionen.

## Neu in 0.1.0+3

- EAN-, GTIN- und UPC-Barcodes lokal scannen, vor der Übernahme bestätigen und
  vorhandenen oder neuen Produkten zuordnen
- aktuellen Gerätestandort ausschließlich auf ausdrückliche Nutzeraktion
  ermitteln, einschließlich Genauigkeit prüfen und erst bestätigt übernehmen
- Ortskoordinaten optional auf einer OpenStreetMap-Karte anzeigen, korrigieren
  und bestätigt in das Ortsformular zurückgeben
- Bewertungskriterien für Produkt-, Gastronomie- und Geschäftsarten lokal
  anlegen, bearbeiten, sortieren, deaktivieren und sicher entfernen
- Kriterienversion, Beschreibung, Reihenfolge und Skalen historisch mit der
  jeweiligen Bewertung erhalten
- Gaststätte innerhalb desselben Restaurantbesuchs optional in einem separaten
  Formular bewerten, ohne Produktbewertungen oder Bestellung zu vermischen
- Produkt- und Ortsverläufe mit Bewertungen, Einzelwerten, Preisen, Mengen,
  Orten, Erlebniszeiten und Herkunft chronologisch anzeigen

## Bereits enthaltener Kernumfang

- lokale Produkt- und Ortsverwaltung
- geplante, aktive, beendete und nachträglich bearbeitbare Restaurantbesuche
  und Einkäufe
- mehrere Produktpositionen je Erlebnis mit Anzahl, Währung und optionalem
  Preis
- typabhängige Produktbewertungen für Getränke, Speisen und sonstige Produkte
- historisch getrennte Preis-, Produkt- und Ortsbeobachtungen
- lokales Profil als Herkunftskennung
- Offline-Barrierefreiheitserklärung und kontextbezogene Vorbereitung von
  Bugreports zur Prüfung auf GitHub

## Datenschutz und Datenhaltung

Alle fachlichen Daten werden ausschließlich lokal auf dem Gerät gespeichert.
Diese Version besitzt keine Telemetrie, keine versteckte Synchronisation und
benötigt für ihre Kernfunktionen keinen Server. Kamera und Standort werden erst
nach einer bewussten Nutzeraktion verwendet; Hintergrund-Tracking findet nicht
statt.

Die manuelle Ortserfassung bleibt offline nutzbar. Nur das Laden der optionalen
OpenStreetMap-Kartenkacheln benötigt eine Netzwerkverbindung. Ein bewusst
vorbereiteter Bugreport wird im Browser geöffnet und erst nach Prüfung durch
den Nutzer auf GitHub abgesendet.

## Bekannte Einschränkungen

- Import und Export sind noch nicht enthalten.
- Geschäfte können innerhalb eines Einkaufs noch nicht getrennt bewertet
  werden.
- Windows und Linux sind vorbereitet, werden mit dieser Version aber nicht
  veröffentlicht.
- Barcode, Standort und OpenStreetMap-Karte müssen noch auf den vorgesehenen
  realen Zielgeräten geprüft werden.
- Die systematische manuelle Barrierefreiheitsprüfung mit TalkBack, großer
  Systemschrift, Gestennavigation und einem kleinen Android-Gerät ist vor einer
  öffentlichen Freigabe noch abzuschließen; siehe Story #30.
- Vor Neuinstallation oder Wechsel des Signierschlüssels gibt es noch keinen
  Exportweg für lokal gespeicherte Daten.

## Installation

1. Die Dateien `taugts-0.1.0+3.apk` und
   `taugts-0.1.0+3.apk.sha256` aus diesem GitHub Release herunterladen.
2. Die SHA-256-Prüfsumme kontrollieren.
3. Unter Android gegebenenfalls die Installation aus der verwendeten
   Download-App beziehungsweise dem Browser erlauben.
4. Die APK öffnen und die Installation bestätigen.

Spätere APK-Updates funktionieren nur, wenn sie mit demselben
Release-Keystore signiert wurden.

## Prüfsumme unter Windows kontrollieren

```powershell
Get-FileHash .\taugts-0.1.0+3.apk -Algorithm SHA256
```

Der ausgegebene Hash muss mit dem Inhalt von
`taugts-0.1.0+3.apk.sha256` übereinstimmen.
