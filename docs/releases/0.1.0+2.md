# Taugt’s? 0.1.0+2

Diese Android-Version von **Taugt’s?** erweitert den vollständig lokalen
Bewertungskern um Restaurantbesuche und Einkäufe als zeitlich nachvollziehbare
Erlebnisse sowie um mehrere Produktpositionen mit Anzahl und optionalem Preis.

## Neu in 0.1.0+2

- Restaurantbesuche und Einkäufe als geplante, aktive oder beendete Erlebnisse
  lokal erfassen und später weiter bearbeiten
- Planungszeitpunkt, tatsächlichen Beginn und tatsächliches Ende getrennt
  speichern, sodass Planung und realer Ablauf unterscheidbar bleiben
- Erlebnisse bewusst beginnen und beenden, ohne frühere Zustände still zu
  überschreiben
- mehrere Produktpositionen einem Erlebnis zuordnen
- je Produktposition eine ganzzahlige Anzahl sowie einen optionalen,
  korrekturfähigen Preis erfassen
- Preise in EUR, USD oder GBP speichern; frühere Preise dienen ausschließlich
  als Orientierung und werden nicht ungefragt übernommen
- Produktbewertungen anhand der Produktart auf passende Kriterien führen:
  Getränke behalten ihr Getränkeset, Speisen erhalten eigene Kriterien und
  sonstige Produkte mindestens Gesamturteil und optionale Notiz

## Bereits enthaltener Kernumfang

- lokale Produktverwaltung für Bier und andere Produkte
- lokale Ortsverwaltung mit Ortstyp und optionalen Detailangaben
- historisch getrennte Produktbewertungen je Erlebnis
- unabhängiges Gesamturteil ohne automatische Verrechnung der Einzelwerte
- lokales Profil als Herkunftskennung
- Offline-Barrierefreiheitserklärung
- kontextbezogene Vorbereitung von Bugreports zur Prüfung auf GitHub
- vollständig lokale SQLite-Datenhaltung ohne Telemetrie oder notwendige
  Serveranbindung

## Datenschutz und Datenhaltung

Alle fachlichen Daten werden ausschließlich lokal auf dem Gerät gespeichert.
Diese Version besitzt keine Telemetrie, keine versteckte Synchronisation und
benötigt für ihre Kernfunktionen keinen Server. Ein bewusst vorbereiteter
Bugreport wird im Browser geöffnet und erst nach Prüfung durch den Nutzer auf
GitHub abgesendet.

## Bekannte Einschränkungen

- Import und Export sind noch nicht enthalten.
- Barcode-Erkennung, Standortübernahme und OpenStreetMap-Karte sind in dieser
  Version noch nicht enthalten.
- Gaststätten können innerhalb eines Restaurantbesuchs noch nicht getrennt von
  den Produktbewertungen bewertet werden.
- Geschäfte können innerhalb eines Einkaufs noch nicht getrennt bewertet
  werden.
- Windows und Linux sind vorbereitet, werden mit dieser Version aber nicht
  veröffentlicht.
- Die systematische manuelle Barrierefreiheitsprüfung mit TalkBack, großer
  Systemschrift, Gestennavigation und einem kleinen Android-Gerät ist vor einer
  öffentlichen Freigabe noch abzuschließen; siehe Story #30.
- Vor Neuinstallation oder Wechsel des Signierschlüssels gibt es noch keinen
  Exportweg für lokal gespeicherte Daten.

## Installation

1. Die Dateien `taugts-0.1.0+2.apk` und
   `taugts-0.1.0+2.apk.sha256` aus diesem GitHub Release herunterladen.
2. Die SHA-256-Prüfsumme kontrollieren.
3. Unter Android gegebenenfalls die Installation aus der verwendeten
   Download-App beziehungsweise dem Browser erlauben.
4. Die APK öffnen und die Installation bestätigen.

Spätere APK-Updates funktionieren nur, wenn sie mit demselben
Release-Keystore signiert wurden.

## Prüfsumme unter Windows kontrollieren

```powershell
Get-FileHash .\taugts-0.1.0+2.apk -Algorithm SHA256
```

Der ausgegebene Hash muss mit dem Inhalt von
`taugts-0.1.0+2.apk.sha256` übereinstimmen.
